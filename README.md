Project Overview

The Contact Management System is a Java-based desktop application developed using Java Swing. It helps users store, manage, search, update and organize contact information through a graphical user interface.

Features

- Password Protection
- Add New Contacts
- Update Contact Details
- Delete Contacts
- Search Contacts
- Favorite Contacts
- Contact Photo Selection and Viewing
- Contact Categories
- Birthday Reminders
- Contact Backup and Restore
- Import and Export Contacts
- Duplicate Contact Detection
- Recycle Bin
- Dark Mode
- Contact History

Technologies Used

- Java
- Java Swing
- Object Serialization
- File Handling
- VS Code

Project Structure

- "Main.java" – Main application and user interface.
- "Contact.java" – Contact data model.
- "contacts_data.dat" – Local contact storage (not included in public releases).
- "contact_photos/" – Local contact photo storage.

How to Run

1. Install Java (JDK 17 or later).
2. Download "ContactManagementSystem.jar" from the Releases section.
3. Open a terminal in the downloaded file's folder.
4. Run:

java -jar ContactManagementSystem.jar
